什么是prompt

2026年8月6日 · 1 分钟 · 145 字 · beyond

Prompt（提示词）本质上就是你给 AI 下达的“指令”或“需求描述”。 它是人与 AI 之间沟通的桥梁，你通过它告诉 AI “做什么”和“怎么做”。

通俗类比#

想象你去餐厅点菜：

  • 烂 Prompt：“来一个菜” → 厨师一脸懵，给你端上来一盘大杂烩
  • 好 Prompt：“宫保鸡丁，300克，鸡丁嫩、花生脆、辣度6分、不加豌豆、配米饭” → 完美出餐

AI 就是那个厨师，Prompt 就是你的点菜单。指令越清晰，输出越精准。

Prompt 的核心组成#

一个完整的 Prompt 通常包含以下几个要素：

要素作用示例
角色（Role）设定 AI 的身份“你是资深 Go 后端工程师”
任务（Task）明确要做什么“帮我写一个 HTTP 中间件”
上下文（Context）提供背景信息“项目用 Gin 框架，Go 1.22”
约束（Constraint）限定范围“不超过 50 行，要有错误处理”
输出格式（Output）指定结果形式“输出完整代码 + 注释”
示例（Example）提供参考样本给一段类似的代码让 AI 模仿

在 AI 编程中的具体体现#

你在 Qoder、Cursor 这类 AI 编程工具中，Prompt 无处不在：

  • 对话框输入：你敲的每一句话都是 Prompt，比如"帮我重构这个函数"
  • 行内指令：在代码编辑器里按 Ctrl+I 弹出的输入框，你写的内容就是 Prompt
  • Rules 规则文件：你之前配置的 .qoder/rules/shell.md，本质上就是一段预设的 System Prompt，告诉 AI 始终遵守某些规则
  • AGENTS.md：同样是 Prompt，只不过是以文件形式持久化存储

两种 Prompt 类型#

  • System Prompt（系统提示词）：定义 AI 的"人设"和行为准则，长期生效。比如你配置的全局 shell 规则就是 System Prompt
  • User Prompt（用户提示词）：你每次对话时输入的具体指令，单次生效

好坏 Prompt 对比#

❌ 模糊的 Prompt：

“优化这段代码”

✅ 精准的 Prompt：

“优化以下 Go 函数，要求：1. 将 O(n²) 改为 O(n log n)；2. 添加 context 超时控制；3. 补充错误处理；4. 代码风格符合 Go 官方规范”

同一个 AI 模型，用不同的 Prompt，输出质量天差地别。所以业界有句话：“AI 编程的核心技能不是写代码，而是写 Prompt。”

一句话总结#

Prompt 就是你对 AI 说的话。说得越清楚、越具体、越结构化，AI 给你的结果就越好。 它不是一种技术，而是一种"和 AI 沟通的能力"。

要不要我整理一份 Go 开发场景下的 Prompt 模板库？比如写中间件、单元测试、代码审查等高频任务的现成模板，你直接改参数就能用。
