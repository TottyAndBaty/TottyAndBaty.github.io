什么是智能体

2026年8月1日 · 1 分钟 · 46 字 · beyond

进入AI编程时代，作为一个古法编程的开发者，必须接受新的事物,本文只做简单的笔记，不涉及深度探讨。

什么是agent?

打开招聘软件，铺天盖地的要求agent开发？作为传统IT从业者，可定一脸懵，chatgpt横空问世的时候，着实震惊了一把，cursor1.0的推出，确实感受到了 AI编程带来的快捷高效，2023年cursor诞生了，下载使用了一阵子，发现很强大。但是尚未体验到agent开发带来的震撼与兴奋。

在人工智能领域，智能体被定义为任何能够通过传感器（Sensors）感知其所处环境（Environment），并自主地通过执行器（Actuators）采取行动（Action）以达成特定目标的实体。

早期的智能体发展经历了如下几个阶段

① 基于模型的反射智能体 拥有内部"世界模型"，能追踪感知不到的信息，具备初级"记忆"。

核心问题：世界现在是什么样子的？

② 基于目标的智能体 不再被动反应，而是主动规划，寻找能达成目标的最优路径。

核心问题：我该做什么才能达成目标？

③ 基于效用的智能体 面对多个相互冲突的目标时，为每个状态打分（效用值），选择满意度最高的行动。

核心问题：哪种行为能带来最满意的结果？

④ 学习型智能体 不再依赖人类预设规则，而是通过与环境互动自主学习，不断优化决策策略。强化学习是实现这一思想的核心路径。

核心问题：怎样通过经验让自己变得更好？

⑤ 演进脉络 恒温器 → 有模型的汽车 → 能规划的导航 → 懂权衡的决策者 → 能自我进化的学习者。这条线索展示了传统AI构建机器智能的发展脉络，也为当下更前沿的智能体范式奠定了基础。

📌 一句话概括：智能体的演进本质上是**从"被动反应"到"主动规划"，从"依赖预设"到"自主学习"**的逐步升级过程。

2022年，ChatGPT横空出世，以GPT（Generative Pre-trained Transformer）为代表的大语言模型的出现，正在显著改变智能体的构建方法与能力边界。由大语言模型驱动的 LLM 智能体，其核心决策机制与传统智能体存在本质区别，从而赋予了其一系列全新的特性。

Agent 的本质就是以大模型为大脑，具备感知、规划、记忆和工具调用四大能力的自主执行系统。它和传统软件的根本区别在于——传统软件是人写好每一步逻辑，而 Agent 是人只给目标，Agent 自己想办法完成
